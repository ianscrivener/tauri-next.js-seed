# Tauri + Next.js

This template should help get you started developing with Tauri and Next.js
 - Tauri v2.8.5 
 - Next.js v14.2.3 


### Install & start
```
# install Tauri CLI via node.js
npm install

# install node.js modules for Next.js 'frontend'
cd src && npm install && cd ../

# Run Tauri
npm run tauri dev
```
